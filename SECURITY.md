# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not publish tokens, private repository content, or exploit details in a public issue.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

## Token hygiene

Use a fine-grained token restricted to selected repositories and the permissions documented in the README. Revoke the token immediately if it may have been exposed. Never place a token in a plan, command-line argument, issue, pull request comment, or repository file.
